🌐 CLOUDFLARE TUNNEL SETUP
═════════════════════════════════════════════════════════════════════════════

1. Install cloudflared (already in C:\Program Files (x86)\cloudflared\)

2. Authenticate:
   cloudflared tunnel login

3. Create tunnel:
   cloudflared tunnel create vscode-cycle

4. Configure C:\Users\%USERNAME%\.cloudflared\config.yml:
   ---
   tunnel: YOUR_TUNNEL_UUID
   credentials-file: C:\Users\%USERNAME%\.cloudflared\UUID.json
   ingress:
     - hostname: vscode-cycle.YOUR_DOMAIN.com
       service: http://localhost:5000
     - service: http_status:404

5. Run tunnel:
   cloudflared tunnel run vscode-cycle

6. Access remotely at: https://vscode-cycle.YOUR_DOMAIN.com

🆘 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Issue: "Port 5000 already in use"
─────────────────────────────────
Fix 1: Change port in start-system.ps1 -Port 5001
Fix 2: Find process: netstat -ano | findstr :5000
Fix 3: Kill process: taskkill /PID <PID> /F

Issue: "Access Denied" errors in web server
──────────────────────────────────────────
Fix: Run PowerShell as Administrator
    Right-click PowerShell → Run as Administrator

Issue: Scripts not running / execution policy error
──────────────────────────────────────────────
Fix: Set execution policy:
    Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser

Issue: Log file encoding error
──────────────────────────────
Fix: Already fixed! New UTF-8 log created on startup

Issue: System tray icon not appearing
─────────────────────────────────────
Fix: Run Task Scheduler → System → explorer → Properties → Enable auto tray
