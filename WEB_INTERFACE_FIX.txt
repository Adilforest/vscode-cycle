ПРОБЛЕМА: "Connection error"
────────────────────────────
РЕШЕНИЕ:
  1. Убедитесь Web Server запущен на порту 8080
  2. Проверьте: http://localhost:8080/ доступен ли
  3. Если не доступен, запустите:
     & 'C:\Users\ГГГ\Scripts\run-as-admin.bat'
  4. Перезагрузите страницу браузера (F5)

────────────────────────────────────────────────────
РЕШЕНИЕ:
  1. Очистите кэш браузера (Ctrl+Shift+Delete)
  2. Закройте и откройте браузер заново
  3. Откройте http://localhost:8080/ в новой вкладке
  4. Проверьте консоль (F12 → Console) на ошибки
  5. Убедитесь что Web Server запущен с правами администратора
